# MNIST_Digit_Classifier
MNIST Digit Classifier, first step to learning ML
A simple neural network built with PyTorch to classify handwritten digits from the MNIST dataset.

## Features
- Manual MNIST binary file loading
- Fully connected neural network
- Training and testing pipeline
- ~97% accuracy after training

## Technologies
- Python
- PyTorch
- NumPy

## How to Run

Clone the repository:

git clone https://github.com/laserFocusDev/MNIST_Digit_Classifier.git

Install dependencies:

pip install -r requirements.txt

Run the model:

python main.py
